CHEVALIER & ROTH – WEBSITE PAKET

START:
1. Ordner entpacken.
2. index.html öffnen.
3. admin.html öffnen, um Produkte, Preise, Texte, Rabatte und Aktionscodes zu verwalten.

WICHTIG:
Diese Version ist ein professioneller Frontend-Prototyp. Produktänderungen werden im Browser gespeichert (localStorage).
Für einen echten Live-Shop, bei dem alle Besucher dieselben Daten sehen und Bilder direkt im Admin hochgeladen werden, muss das Projekt noch an eine Datenbank / Storage-Lösung wie Appwrite angebunden werden.

BILDER:
Siehe BILDER-HIER-REIN.txt.

WICHTIGE DATEIEN:
index.html = Startseite
kollektion.html = Kollektion
produkt.html = dynamische Produktseite
cart.html = Warenkorb
profil.html = Kundenkonto
admin.html = Adminbereich
style.css = komplettes Design
cr-store.js = Produkt-/Shopdaten
shop.js = Shop-Funktionen
logo.PNG = Logo
